# ERP EnterpriseCloud · Frontend Skills

Incluye `AGENTS.md` y siete skills enfocadas en React + TypeScript, dashboard, API, autenticación/rutas, formularios/tablas, accesibilidad responsive y pruebas.

## Instalación
Copia `AGENTS.md` a la raíz del frontend y copia la carpeta `.agents/skills/` a la raíz del mismo proyecto.

## Importante
Las skills son instrucciones de trabajo. Antes de programar, el agente debe revisar el código y adaptar la arquitectura a las dependencias y contratos reales existentes.
