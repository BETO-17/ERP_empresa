# Skill: Accesibilidad y diseño responsive

## Accesibilidad
- Usa HTML semántico y controles nativos cuando sea posible.
- Asocia cada input con su etiqueta.
- Mantén foco visible y orden lógico de tabulación.
- Los modales deben gestionar el foco y permitir cierre por teclado cuando sea apropiado.
- Comunica errores con texto, no solo con color o iconos.
- Añade nombres accesibles a botones con solo icono.
- Respeta preferencias de movimiento reducido.
- Mantén contraste suficiente en texto, bordes y estados.

## Responsive
- Prueba como mínimo escritorio, tableta y móvil.
- Evita anchos rígidos que provoquen desbordamiento de toda la página.
- La navegación lateral debe adaptarse a pantallas estrechas.
- Las tablas deben tener una estrategia móvil explícita.
- Formularios y filtros deben reordenarse sin perder jerarquía.
- Los gráficos deben conservar legibilidad.

## Verificación
- Recorre flujos principales solo con teclado.
- Verifica foco, etiquetas, mensajes de error y estados de modal.
- Ejecuta las herramientas de accesibilidad disponibles en el repositorio.
- No declares conformidad completa con WCAG sin una evaluación suficiente.
